# Contributing to Haang

Thank you for helping build **Haang** — a free, open-source POS and inventory app for Cambodian SMEs. Contributions of code, translations, documentation, bug reports, and ideas are all welcome. អរគុណសម្រាប់ការចូលរួម!

## Developer Certificate of Origin (DCO)

To keep the project's provenance clean, we use the [Developer Certificate of Origin](https://developercertificate.org/). It's a simple statement that you have the right to submit your contribution.

**Sign off every commit** by adding a `Signed-off-by` line — Git does this for you with the `-s` flag:

```bash
git commit -s -m "feat: add my improvement"
```

This appends a line like:

```
Signed-off-by: Your Name <your.email@example.com>
```

Use your real name and a valid email. Pull requests whose commits are not signed off may be asked to amend before merging.

## How to contribute

1. **Open an issue** first for significant changes so we can discuss the approach.
2. **Fork** the repo and create a branch (`feat/...`, `fix/...`, `docs/...`).
3. Make your change, keeping the style consistent with the surrounding code.
4. **Sign off** your commits (`git commit -s`).
5. Open a **pull request** describing what changed and why.

## Good areas to help

- **Translations** — Khmer is the priority, plus the other supported languages.
- **Bug fixes** and small UX improvements for low-end mobile devices and offline use.
- **Documentation** in `docs/`.
- **Accessibility** and performance on slow networks.
